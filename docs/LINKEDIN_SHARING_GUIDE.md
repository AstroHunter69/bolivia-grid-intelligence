# LinkedIn Sharing Guide

Recommended format:

1. One polished summary image as the first slide.
2. Two or three dashboard screenshots after it.
3. A short screen recording only if the dashboard interaction is smooth and readable on mobile.

Suggested carousel:

- Slide 1: project summary with problem, model, RL dispatch framing, and headline metrics.
- Slide 2: demand forecast comparison.
- Slide 3: plant map or dispatch optimization tab.
- Slide 4: 40-day backtest metrics and caveats.

Suggested video:

- 20 to 35 seconds.
- Start on the overview tab.
- Move the slider once.
- Switch to prediction.
- Switch to plant map or optimization.
- End on the GitHub repository or report link.

Posting angle:

> I built a local research prototype for Bolivia electricity-demand forecasting and dispatch-support simulation using CNDC data. The current version combines a full-day-ahead demand model, strict backtesting, and a reinforcement-learning framing for reserve adjustment and renewable integration studies.

Keep the caveat visible:

> Monetary values are cost-proxy estimates, not audited system savings. Dispatch simulation is capacity-aware but not yet full unit commitment, hydrology, or network-constrained.
